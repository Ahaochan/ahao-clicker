# Ahao点击器

一款Android自动点击器：可以在设定时间点击一次，也可以按顺序循环点击多个位置。拖动屏幕上的准星选位置，用悬浮时钟对照时间。

支持 **Android 8.0及以上**，当前版本为 **0.2.0**。项目还在持续完善，目前只支持Android。

## 下载安装

推荐直接[下载最新APK](https://github.com/Ahaochan/ahao-clicker/releases/latest/download/Ahao-clicker-latest.apk)，下载后在手机上打开安装。也可以到[版本下载页](https://github.com/Ahaochan/ahao-clicker/releases)查看历史每日版。

如果想下载某次提交的测试包，登录GitHub，打开[构建记录](https://github.com/Ahaochan/ahao-clicker/actions/workflows/android.yml)，选择成功的运行，在页面底部“构建产物（Artifacts）”下载`debug-apk`，解压得到`app-debug.apk`。

两条工作流分工不同：**Android checks负责检查和上传测试包，Daily APK负责发布Release。** 因此，普通检查成功后没有新Release是正常的；需要持续覆盖更新时，优先使用Release里的每日版。

更新时直接覆盖安装，保留已有设置。如果提示“签名不一致”，先确认下载的版本和原安装来源，不要急着卸载，以免丢失设置。每日版本使用固定的公开测试签名，不属于正式稳定版。

## 第一次使用

| 页签 | 可以做什么 |
| --- | --- |
| 自动点击 | 启用无障碍服务、打开定时或多点浮窗、设置悬浮时间同步间隔 |
| 时间同步 | 查看各来源时间、点击选中并校时、长按拖动排序 |

1. 打开“自动点击”页，启用 **Ahao点击器无障碍服务**，返回后确认状态是绿色“可用”。
2. 打开“时间同步”页，点卡片选择一个时间来源并校时。选网络来源时，先等它成功同步；不需要网络校时可以选“本地时间”。
3. 返回“自动点击”页，打开“定时点击”或“多点点击”浮窗。两种浮窗只能打开一个。

浮窗由无障碍服务提供，不需要再开普通悬浮窗权限。**打开浮窗不会开始点击，按播放才开始；按方块停止，按右上角×停止并关闭。**

### 定时点击一次

1. 拖动准星，对准要点击的位置。
2. 点击浮窗里的“开始点击”时间，用四列滚轮选择时、分、秒、毫秒，然后确定。毫秒每格10ms，可选000～990。
3. 按播放，等待到点点击一次。等待时仍可移动准星，点击使用最新位置；临近触发时会短暂收起准星，为点击做准备。

距定时目标不到或等于1分钟、还没启动时，浮窗的当前时间变红，立即提示“点击器没有启动”，之后每10秒提示一次。系统限制后台弹出提示时，文字显示在浮窗内。按播放启动或目标过期后，当前时间恢复原色，提示停止。

应用记住你最后确认的分、秒、毫秒，每次新开浮窗时，按所选时间来源自动选小时：

| 记住的时间 | 所选来源显示12点时，新浮窗默认显示 |
| --- | --- |
| 59分59秒990毫秒 | 12:59:59:990 |
| 00分00秒000毫秒 | 13:00:00:000 |

规则是：分、秒、毫秒合计**大于30秒，取当前小时；不超过30秒，取下一小时**。23点的下一小时是次日0点。第一次没有记录时取所选来源的当前时间；取消编辑不会覆盖记忆，重复打开已显示的浮窗也不会重置时间。

选择时间时不需要填写日期：确认后安排在这个时刻下一次到来时执行，今天已过就安排到明天。按播放时，如果时间已经过期，会先打开滚轮让你重新确认；失败或过期不会自动补点。

### 多点循环点击

1. 打开多点浮窗，拖动已有准星到第一个位置，按“＋”继续加点。
2. 点一下准星，可以设置它的等待时间，也可以删除。默认等待1000ms，也就是1秒。
3. 按播放，按1、2、3……的顺序点击，最后一个点完成后从1继续循环。
4. 按方块停止。运行时准星保留在屏幕上，不会拦住自动点击。

第一个点的等待时间从按播放开始算，后续点从上一个点开始点击时算；每轮回到第一个点也按它的等待时间执行。目前通过手动加点设置位置，还不支持录制手指操作、长按或滑动。

### 移动和缩放浮窗

拖动顶部的四向箭头可以移动浮窗；拖动左下角或右下角可以缩放。按钮始终放在同一行，小窗会缩小图标和留白。定时和多点浮窗分别记住大小，缩放浮窗不改变准星位置；点击运行期间不能移动或缩放控制窗。

## 时间同步怎么用

内置京东、淘宝、阿里云、腾讯云、Cloudflare和本地时间。在“时间同步”页点击卡片任意位置，就会选中该来源并同步一次；再次点已选卡片也可刷新。请求仍遵守来源最短间隔，重复操作会复用等待中或进行中的请求，可能需要稍等才能看到新结果。本地时间直接读取手机时钟，不联网。

卡片单列排列，名称在左，时间和与手机的差值在右；括号内单位是毫秒，正数表示快于手机，负数表示慢于手机。下面的小字是最近一次同步成功时的手机时间，失败时保留上次成功记录；选中的来源由圆点和边框标记。

长按卡片拖动时，其他卡片会平滑让位，实时预览新顺序；在列表内松手保存，拖到外面、取消或切换页签则还原。排序不会改变已选来源或触发校时。

### 设置悬浮时间同步间隔

回到“自动点击”页，在两个浮窗入口下方填写“悬浮时间同步间隔（毫秒）”，然后按“保存并同步”。可填1000～86400000，默认60000ms（1分钟）；保存后会对所有来源同步一次，可切到“时间同步”页查看结果。

只修改输入框还不会生效，切换页签或旋转屏幕会保留未保存的输入。点击来源卡片使用已保存的间隔。任务运行时不能切换来源或修改间隔。

间隔决定浮窗对所选来源尝试校时的频率，各来源还有最低限制：

| 时间来源 | 最短同步间隔 |
| --- | --- |
| 京东、淘宝 | 1000ms（1秒） |
| 阿里云、腾讯云、Cloudflare | 60000ms（1分钟） |
| 本地时间 | 不联网，直接使用手机时间 |

例如保存7777ms后，浮窗选择京东或淘宝时，会约每7.777秒尝试同步；选择其他三个网络来源时，仍至少间隔1分钟。网络请求不一定每次成功，可以查看卡片上的最近成功时间。

### 什么时候会同步

- **时间页变为可见**：所有来源各同步一次，包括切到该页、在该页返回前台或重建页面。停留时只刷新显示，不反复请求。
- **点击来源卡片**：仅同步该来源一次；**保存并同步**：保存间隔并对所有来源同步一次。
- **浮窗打开期间**：只周期同步所选来源，离开时间页后仍继续；关闭浮窗后停止这项周期同步。时间页同时打开时，各来源仍会完成本轮页面校时。

仅停留在“自动点击”页不会启动校时。应用退到后台时，会取消只供页面查看或手动保存使用的未完成校时；已打开浮窗仍按所选来源继续同步。

## 时间能有多准？

这里要分开看：**浮窗显示的时间准不准**，以及**到点后目标什么时候真正收到点击**。

浮窗用最近一次成功同步的结果计算当前时间，不会靠每次刷新加一毫秒。定时同步可以更新它，但网络来回耗时不同，仍可能把时间校偏；目标应用和手机调度也会影响点击实际收到的时刻。因此，显示了毫秒不代表每次误差都小于50ms，当前版本没有这样的保证。

任务最后5秒会固定本次使用的时间参考，避免临近触发时再次校时改变目标。锁屏、服务断开等情况会停止任务，重新连接后需要手动开启。建议保持手机亮屏、目标页面可点击，先用不重要的目标试一次。详细测量条件和历史数据见[精度分析](docs/ACCURACY_CAPTURE_RESULTS.md)及[测量验证](docs/MEASUREMENT_REPAIR_RESULTS.md)。

## 遇到问题

- **无障碍状态是红色**：去系统设置确认本应用服务已开启，返回后再看是否变绿。具体入口随手机系统不同。
- **浮窗消失**：先记下复现步骤、当时是否已播放，以及首页无障碍状态；保留现场，不要先清空应用数据。小米系统录屏导致浮窗关闭的问题已有修复和[排查记录](docs/RECORDER_OVERLAY_DIAGNOSIS.md)。
- **更新安装失败**：确认Android版本满足要求，并检查是否为签名冲突；不要直接卸载旧版来解决。

可以到[Issues](https://github.com/Ahaochan/ahao-clicker/issues)反馈。请附手机型号、Android版本、应用版本、复现步骤、预期和实际结果；截图先遮掉私人信息。

## 从源码构建

需要JDK 17、Android SDK Platform 36。Android Studio或装好Android插件的IDEA都可以打开项目；SDK位置由IDE或本机`local.properties`指定。

Windows在项目根目录运行，先把示例JDK路径换成自己的：

```powershell
$env:JAVA_HOME = 'D:\JDK\jdk-17'
.\scripts\build.ps1 -Action check
```

脚本会运行单元测试、Lint，再生成Debug和Release。只想打包时用`-Action assemble`。**Gradle下载缓存不能放在C盘**：保留已有D/E盘`GRADLE_USER_HOME`；没有设置时，脚本会使用项目内`.gradle-user-home`并检查目录，项目也应放在非C盘。默认优先使用国内HTTPS镜像，完整配置见[工程说明](docs/decisions/0002-android-project.md)。

可直接安装的测试包位于`app/build/outputs/apk/debug/app-debug.apk`。Release产物在`app/build/outputs/apk/release/`，正式分发前需要自行签名。

要通过电脑安装，连接手机并允许USB调试，使用SDK的`adb`；将下面的`SERIAL`换成第一条命令列出的目标手机序列号，状态应为`device`：

```powershell
adb devices -l
adb -s SERIAL install -r -t .\app\build\outputs\apk\debug\app-debug.apk
adb -s SERIAL shell am start -n com.ahao.clicker/.MainActivity
```

每日打包计划在北京时间08:17执行，也可进入[Daily APK](https://github.com/Ahaochan/ahao-clicker/actions/workflows/daily-apk.yml)，点击“Run workflow”，选择`master`手动运行。它使用固定公开测试签名，密码`android`，无需配置Secret；成功后创建Release，附带APK、SHA-256校验文件和构建来源信息。首次手动发布已验证成功，GitHub定时任务仍可能延迟。签名兼容、可选自定义签名和发布配置见[每日打包说明](docs/decisions/0020-daily-apk.md)。
