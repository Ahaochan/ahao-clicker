## 第三步：时间同步与定时点击（2026-10-24）

按用户要求采用 TDD：先编写和运行失败测试，再实现最小代码，最后回归测试。先做功能与边界正确性，性能以真机测量为准。

### 功能与语义

- 外部时间源：可配置 HTTPS URL、HTTP Date 或 JSON 时间戳（毫秒/秒）、JSON 字段路径、同步间隔；支持立即同步与周期同步。
- 同步采用单调时钟和请求往返时间中点估计偏差；超时/过慢/无效响应不覆盖上次成功样本，不修改系统时间。
- 连点：指定点位、开始/结束绝对时刻、最多点击次数和完成后等待间隔。次数或时间窗先达到即停止，不补发堆积的点击。
- 多点：用户明确要求录制时执行实际点击。采集窗口临时变为透明且不接收触摸，等待更新后由无障碍服务派发点击；完成后缓冲恢复采集，失败停止。录制期间按提示逐点操作，不支持快速触摸的无损录制；回放间隔可编辑并按顺序循环。
- 开始执行时冻结本次时间参考，期间时间同步不会使任务时间跳变。没有成功同步时明确显示使用设备时间。
- 周期同步在用户开启且应用进程存活时执行；不申请精确闹钟，不承诺休眠或进程被杀后仍按毫秒执行。

### 资源约束

调度只保留下一次动作与截止/超时回调，不展开重复序列；录制最多 500 点，网络响应最多 64 KiB，单次网络连接有超时，禁止无界日志。屏幕旋转、尺寸变化、锁屏、服务断开和网络配置变化有明确停止或取消路径。
