# ADR 0019：页面单次初始化与浮窗选中源周期同步

- 日期：2026-11-02。
- 状态：已实现，验证范围见本轮验收索引。
- 更新ADR 0006、0018的观察者规则，不调整授时估算、点击截止算法及最后5秒参考锁定。
- 后续：2026-11-03增加整卡点击选中并单次同步选中来源，继续复用排队/在途请求和最短间隔，见[ADR 0022](0022-source-card-interaction.md)。
- 后续：保存入口移到自动点击页，显式单次需求在当前页持有，进入比较页移交，后台释放；周期需求和普通首页不自动请求规则保持，见[ADR 0023](0023-interval-on-click-page.md)。

## 决定

1. `TimeSources`集中管理两种需求：时间页每次从不可见变为可见时，全量同步一次；浮窗/显式任务只周期同步选中来源。MainActivity前台本身不持有同步订阅。切换来源、刷新设置和页面数字刷新不触发全量初始化。
2. 页面和浮窗同时打开时，全页初始化仍只有一次，选中源随后周期同步。单个来源有排队的一次性请求或正在请求时复用；不重复请求，也不因周期需求开关打断它。进入页面会把已有周期等待改为尽早一次，继续尊重独立节流。页面退出取消没有浮窗需求的请求；浮窗关闭停止后续周期请求，尚可见页面本轮一次性请求可以完成。两者都关闭时取消网络、排队任务并拒绝旧代次结果。
3. 周期请求使用配置间隔与来源最小间隔约束，保留HTTP 1000ms、NTP 60000ms下限。请求时间按开始时刻计算，不堆积补发。手动保存并同步仍全量一次，并维持现有选中源周期订阅。页面一次性失败不重试；重新进入或手动同步可重试。返回前台时间页、重建该页视为重新进入。
4. `SyncState.lastSuccessEpoch`记录成功采纳样本时的本机墙上时间，仅用于卡片小字；`lastSuccessElapsed`继续用于样本有效期。显示最近成功完成节点而非源时间或请求开始时间，失败不覆盖，未成功与本地无需同步分别明确标记。只在成功时间变化时格式化，不逐帧格式化、不写偏好。
5. 保留各来源独立样本、失败状态、本地无网络、配置活动任务保护和来源排序；无新依赖、模块或线程。提供普通构造器工厂以便假Provider测试需求协调，设备测试用真实网络管理器与独立TLS夹具核对请求次数，生产默认构造不变。

## 边界评估

A2的配置操作继续复用TimeSettingsController，网络需求协调留在time模块，页面仅报告可见性和渲染。A1不修改任务编排，A4没有协议变化，本轮不搬迁接口目录；这次减少无需求请求，不承诺点击精度收益。

## 验证标准

- 单测先复现全量周期、缺少入页请求及手动全量周期的问题，再验证进入/停留/重进、叠加浮窗、切换来源、手动同步和关闭需求。
- 模拟器TLS服务按路径统计真实收到的请求，覆盖单次成功/失败、周期转移、在途复用、取消后拒绝旧结果；生产页通过现有关闭式探针核对实际来源尝试，成功时间UI用TLS夹具提供确定性样本。
- 回归本地时间、排序、滚轮、定时实际接收、取消与多点循环、横屏大字号。采集只证明本次功能生命周期，不外推50ms精度或其他设备性能。
