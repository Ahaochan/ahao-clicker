# ADR 0009：浮窗直接编辑开始时间

- 日期：2026-10-26。
- 状态：已实现；48 个单测、完整 25 项模拟器场景、Lint 和 Debug/Release 构建通过。
- 用户选择：点击时间编辑；播放直接启停，时间缺失或过期时才弹出选择器。
- 取代旧版首页时间按钮和“准备定时”步骤，不改变核心一次资格和最新准星取点规则。

首页移除一次说明、准备按钮和重复状态；后续按用户要求继续移除整个第三步、模式与点位摘要，第二步只提供定时浮窗入口和禁用的多点录制占位入口。浮窗仅展示图标、当前时间和开始时间，后者带编辑图标、点击反馈和可读名称。坐标与持续任务状态不再占用浮窗；终态用图标复位和短提示表达。

复用现有四列原生滚轮，可由 AccessibilityService 使用 TYPE_ACCESSIBILITY_OVERLAY 创建 AlertDialog，不引入 Activity 跳转、普通浮窗权限或新依赖。点时间进入时确认仅保存；播放无有效时间时进入，确认后开启；取消不保存、不执行。正在运行时仍要求先停止再编辑。服务持有至多一个对话框，在取消、关闭、断开、旋转和屏幕中断时销毁，不自动恢复任务。

主页面不再持有定时目标草稿，目标由设置存储和服务维护，避免两个入口值不同步。去掉不再显示的倒计时/坐标文案计算，保留可取消的生命周期检查与点击停止路径。

2026-10-30 用户更新默认值规则：每次新开浮窗以当前参考日期和小时搭配最后一次滚轮确认的分、秒、毫秒，首次没有记录时全部取当前参考时间。一个偏好值只编码小时内的毫秒位置（0..3599999），不含日期和小时；仅在有效滚轮确认回调中与任务目标一并保存，取消和新建草稿不更新记忆，损坏记录回退当前时间。关闭后重开才重置；已有窗口重复入口保持微调。初始化只保存草稿，既不计算次日目标也不派发点击；滚轮确认时继续按下一次发生时刻解析，播放仍需有效校时和未来目标。此规则替代此前“每次全部取当前参考时间”的默认值。

准星采用 Canvas 原生绘制的 FPS 四段短线、中心空隙和小点，明绿配深色描边；64 dp 拖动区域保持，绘制不分配位图或引入动画循环。

方案与验收边界见 [UI/UX V4](../UI_UX_V4.md) 和 [验证记录](../VERIFICATION.md)。
