# ADR 0022：来源卡片点击校时与实时拖动预览

- 日期：2026-11-03。
- 状态：已实现；单测、模拟器与真机安装范围见[验证记录](../VERIFICATION.md)。
- 用户要求点击卡片即选中并同步一次选中来源，拖动卡片时实时移动并有动态效果。更新ADR 0018、0019、0021的交互入口。

## 决定

1. 卡片背景、名称、时间及最近成功时间均可点击，复用TimeSettingsController统一检查活动任务、保存选择、应用配置并请求一次选中来源；重复点击当前来源同样请求。同步使用已保存的间隔，未确认输入不应用。
2. TimeSources负责单来源请求，保持浮窗订阅状态。TimeSyncManager继续复用排队/在途请求、遵守HTTP 1000ms及NTP 60000ms最短尝试间隔；本地来源直接读取系统时间，不联网。点击不触发其他来源全量同步，也不新增页面周期请求。
3. 长按使用系统拖动影子，经过其他位置时立即预览新顺序，通过有界位移动画平滑让位。保持来源身份及原始顺序，只有有效放下才保存；外部放下、取消、切页或旧页面事件回滚预览。拖动不选择来源、不保存同步间隔、不请求同步。
4. 来源卡片继续单列、名称与时间同排。复用现有Views和存储，不增加依赖、模块、线程或业务轮询；A2继续集中配置操作，排序预览和动画留在页面，不修改授时估算和点击调度。

## 验证标准

- 先复现整卡点击无效和松手前没有预览的问题；单测覆盖只请求选中来源、重复点击、活动任务阻止、保存顺序和未确认间隔隔离。
- 设备验证点击请求次数、复用、周期需求保持和本地无网络；拖动在松手前已有新顺序及非零动画位移，落下保存、外部取消回滚、选择和草稿保持、重建恢复。
- 完成标准单测、Lint、Debug/Release，检查横竖屏和大字体布局；真机覆盖安装保留用户配置，区分功能回归与精度测量。

## 实现边界

固定拖动开始时的行中心作为插入槽位，避免卡片动画经过指针时反复交换。只调整现有子视图的行号和顺序，不拆离持有原生拖动的来源视图；下一次布局后从旧可见位置过渡到新位置，取消旧动画和过期布局回调。隐藏页面时回滚未提交预览并清理动画，不保留逐帧回调或额外线程。

事件语义参考[Android DragEvent](https://developer.android.com/reference/android/view/DragEvent#ACTION_DRAG_LOCATION)，子视图调整参考[ViewGroup](https://developer.android.com/reference/android/view/ViewGroup#bringChildToFront(android.view.View))；实际动态移动和取消结果另由设备验收确认。
