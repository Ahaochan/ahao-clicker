# ADR 0006：双页签与独立时间功能包

- 日期：2026-10-26。
- 状态：已实现；39 个单测、18 组模拟器场景、Lint 与 Debug/Release 构建通过。京东旧接口实测不可用，限制单列。
- 后续：京东已改用 OPTIONS 响应头，见 [ADR 0007](0007-jd-options-time.md)；下方保留双页签首轮的旧接口记录。
- 取代 ADR 0004 中独立 Activity、固定分钟下拉框和只有三个 NTP 来源的界面决定；保留一次性任务与停止语义。

## 决定

首页使用两个原生页签“自动点击”“时间同步”，不新增 UI 依赖。MainActivity 管理页签与点击入口；app/time 管理来源目录、网络协议、JSON 解析、校时状态和时间页控制器。core 保留时间参考、来源定义、限频与格式规则。这是功能包边界，不为页签另建空的 Gradle 模块。

在原有 NTP 来源之外增加京东、淘宝的 HTTPS 时间字段适配。每个来源独立保存样本、失败、请求计划与取消代次，所有来源共用两个可回收工作线程，避免每来源常驻线程。选中来源供任务与悬浮时钟使用，开始任务时仍冻结参考；查看或保存来源不启动点击。

时间页两列显示来源名称和三位毫秒/本机差值。每 100 ms 更新显示，网络按可输入的毫秒间隔调度；HTTP 最低 1000 ms、NTP 最低 60000 ms。默认与历史配置保持 60000 ms，超出范围明确报错。退出比较页停止其他来源，应用无观察者时全部暂停。

## 接口与边界

- 京东：`https://api.m.jd.com/client.action?functionId=queryMaterialProducts&client=wh5`，只读取响应中的 `currentTime2`，不传用户凭据或商品参数、不执行业务操作。
- 淘宝：`https://acs.m.taobao.com/gw/mtop.common.getTimestamp/1.0/`，读取 `data.t`。
- 以上是公开响应适配，不视为有可用性保障的专用授时服务；可达性写入验收记录，失败不得虚构时间或悄悄换源。淘宝需 AppKey 的 `taobao.time.get` 与本实现不是同一个接口。
- 正常 HTTPS 校验、响应上限、请求超时和缓存拒绝继续生效。不因接口异常关闭证书校验或添加用户登录流程。
- 三位毫秒是格式单位，不表示绝对精度、逐毫秒绘制或硬实时点击保证。
- 2026-10-26 模拟器诊断：京东该接口 HTTP 200 返回 `{"code":"2","echo":"the current API does not exist"}`，不同请求头与常见参数无效，另一个旧地址重定向而未返回时间；本轮保留京东卡片并标记同步失败。淘宝和三个 NTP 来源在整组验收中成功。可达性只是当次网络结果，不是持续可用性保证。
- 本轮回归还发现服务无条件把所有配置通知当成屏幕变化。已先补失败测试，再把坐标标识统一为物理尺寸/旋转，仅真实变化才停止及作废点位；旧格式升级需重新定位一次。

## 验证

先增加内置来源映射、间隔范围、独立限频、正负/零偏差与未同步格式的失败测试，再实现。模拟器验收覆盖两列几何布局、数字错误输入、实时时钟推进、页签和未保存输入重建、切页取消、样本隔离、迟到响应丢弃及原点击流程。结果见 [VERIFICATION.md](../VERIFICATION.md)。
