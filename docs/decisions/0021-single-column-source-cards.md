# ADR 0021：时间数据源卡片采用紧凑单列

- 日期：2026-11-03。
- 状态：已实现；模拟器与真机验证范围见[验证记录](../VERIFICATION.md)。
- 用户反馈名称上下留白过宽、时间换行，明确接受将双列改为单列；更新ADR 0006、0018的页面呈现。
- 后续点击校时与实时拖动让位见[ADR 0022](0022-source-card-interaction.md)，本决定的单列和名称时间同排样式保留。

## 决定

1. 来源卡片始终按单列纵向排列，初始化和拖放重排使用同一布局参数，继续按来源名称保存顺序。
2. 名称行最小触摸高度由56dp收紧为48dp，去除额外文字内边距；卡片上下内边距收紧为4dp，左右仍为8dp。保留系统选择控件、选中背景和长按拖放。
3. 用户随后要求利用卡片右侧空间，名称与时间改为同排：左侧名称占两份宽度，右侧等宽时间占三份并右对齐，为Cloudflare等长名称保留空间；下方保留成功时间小字。大字体和状态长文案可在左侧换行，时间与本机偏差保持同一行，取消强制折行和两行占位。时间字默认14sp，可按实际宽度自动缩小至10sp；不截断毫秒或偏差。
4. 仅改变呈现；复用TimeSettingsController和现有拖放身份、取消及重建保护，不修改同步入口、来源节流、时间参考或点击算法。A2不涉及配置入口变化，无需额外职责迁移。
5. 2026-11-03按用户截图进一步精简：移除卡片上方“内置数据源”标题、点选/拖动提示和下方“当前参考”汇总，页面直接显示卡片；选中标记及各卡片的时间、同步记录继续显示。

## 验证标准

- 更新已有双列几何验收，检查单列宽度与纵向位置、时间实际行数和完整文字布局。
- 在横竖屏及大字体下检查文字、滚动与保存入口；真实长按拖放后仍保持单列，取消与重建保留顺序和选择。
- 运行标准单测、Lint、Debug/Release构建，在已连接手机覆盖安装查看正常字号样式，保留配置；不据此报告新的授时或点击精度。
