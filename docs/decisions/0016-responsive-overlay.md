# ADR 0016：小尺寸响应式控制浮窗

- 日期：2026-10-30。
- 取代ADR 0015中按按钮数量固定最小宽度和56dp按钮的规则；透明度、角落缩放、会话尺寸和执行中冻结继续沿用。
- 更新：[ADR 0017](0017-overlay-size-memory.md)取代会话尺寸规则，定时单点与多点浮窗分别记忆宽高，关闭重开与进程重启后恢复。

最小宽度降为128dp。用户最新明确要求：播放/停止、加号、移动、关闭只能同排，因此取消最初的两行方案。宽窗按钮48dp；窄窗按可用宽度缩小按钮宽高、图标和内边距，不再坚持48dp触摸尺寸。图标最大24dp，并随按钮缩小；复用原控件、监听和可读名称，不整体缩放窗口或影响准星。

当前时间行缩为32dp，Canvas绘制按可用宽度与字形高度取较小比例，保留完整24小时制毫秒。定时时间固定单行、原生自动适配字号，宽窗显示“定时 时间”，小窗只显示时间，可读名称仍包含用途。保留点击打开四列滚轮。宽度小于224dp时内边距收至4dp；恢复宽边距的断点留出四个按钮及像素舍入余量，避免加宽后再次换行。底角区域32dp高、48dp宽，减少专用缩放行的占用。准星不变。

缩放下限根据新宽度重新计算单行页头、时钟、定时时间及角标所需高度，小窗页头更矮。页头、底角不滚动，播放/停止和关闭常显。默认窗口也减少垂直留白；主页面表单的56dp触摸尺寸不变。此前两行的验收作为历史记录保留，不再代表当前行为。

布局测量和断点变化时才重排控件、调整标签，不重建窗口，不增加常驻任务、生产依赖或位图。计时取值、调度与准星输入规则不变；本轮不承诺新的性能或精度结果。

验证覆盖布局边界、按钮不相交、短区域大字号时钟；模拟器以纵屏正常字号和横屏1.5倍字号缩到128dp，检查时间完整、触摸编辑、加号/播放/停止和加宽恢复。与标准构建、既有缩放和实际接收点击回归一同记录，较低API与真机另行验证。
