# ADR 0014：多点点击浮窗

- 日期：2026-10-30。
- 状态：已实现；核心单测及模拟器定向功能验收通过，真机未验证。

第二步启用多点点击入口，取代禁用的录制占位。2026-10-30用户更新为按中心序号持续循环，直到按浮窗停止，不在一轮后结束；通过加号手动增加点位，不做实际触摸录制。定时与多点浮窗互斥。顶部为播放/停止、加号、移动、关闭，保留当前时钟，移除定时设置。

每点默认延迟1000ms，支持0..86400000ms整数。首点相对播放，后续相对上一点的派发开始；末点后按第一点的延迟进入下一轮。核心使用单调绝对时刻，单个点也持续循环；Android无法直接观测其他应用实际DOWN，因此用无障碍派发时刻近似点击开始，验收另核对独立目标DOWN。上一手势尚未完成时不重叠派发，回调已晚于截止则串行执行下一点，失败点不自动补发。0ms通过至少1ms的单调调度刻度让出执行机会；独立索引始终处于固定列表内，累计计数饱和而不溢出，不积累轮次历史。

采用独立纯Kotlin序列执行器，不改变现有ClickRunner/OneShotRunner规则；保留拒绝、取消、超时和旧回调失效，异常停止不会自动恢复。列表最多50点，配置/点位变化保存到独立偏好，屏幕坐标空间变化后不复用旧位置。开启默认一个点，轻点准星编辑延迟并可删除，中心序号随顺序更新。

播放时冻结序列快照，保留全部准星的窗口、可见性和不透明度，仅开启FLAG_NOT_TOUCHABLE让触摸穿透，至少150ms等待输入标志生效；默认1000ms延迟包含准备时间，极短首延迟以准备就绪为下限。停止后准星仍可见，留出500ms输入排空再恢复可拖动和编辑，关闭/切换/中断取消该恢复回调。运行中禁止增点和编辑，控制条始终提供停止。屏幕关闭、显示尺寸变化和服务断开停止，不自动恢复。无新线程、生产依赖、忙等待或后台高频轮询。本规则取代初版的单轮执行和播放时隐藏准星。

对话框确认/取消及控制条延迟回调以当前会话和窗口身份检查，旧窗口不能修改新会话。序列草稿独立保存，不覆盖定时的点位或分秒毫秒记忆。中心数字使用原生Canvas和缓存Paint绘制，不分配位图或给准星增加刷新循环。公开入口需要服务就绪，否则复用既有用途说明和设置引导。

平台依据：[无障碍派发与完成/取消回调](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService#dispatchGesture(android.accessibilityservice.GestureDescription,android.accessibilityservice.AccessibilityService.GestureResultCallback,android.os.Handler))、[无障碍浮窗类型](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_ACCESSIBILITY_OVERLAY)。API完成与目标实际接收分别记录；本轮是功能验收，不承诺多点点击的硬实时精度。
