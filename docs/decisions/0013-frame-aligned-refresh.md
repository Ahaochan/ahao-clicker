# ADR 0013：独立截止下的状态轮询与帧阶段刷新

- 日期：2026-10-28。
- 状态：保留有界轮询优化；帧阶段绘制候选已撤回。严格每次 50 ms 尚未通过。
- 补充 ADR 0012，保留现场取时、单一可取消请求、停止路径及输入提前准备规则。

## 决定与理由

点击截止已有独立异步调度，时钟由 onDraw 现场取时，状态提示最多每 250 ms 更新。原来的最后五秒 33 ms 状态轮询重复做来源/生命周期检查，却不能让被绘制阻塞的主线程立即派发。改为可见时固定 100 ms，隐藏时仍为 250 ms；来源重校时的五秒锁定规则、屏幕关闭广播和独立截止不变。

曾测试把普通队列中的 `postDelayed(16)` 改为 `postOnAnimationDelayed(24)`，现场取时和单一可取消回调保持不变。静默对照中画面滞后 p95 为 58 → 47 ms，但最大 94 → 110 ms、CPU 区间中位 29.33% → 30.67%；绝对估算误差最大 95 → 128 ms。点击配对同样没有一致改善。小样本不能断定必然回退，但证据不足以支持保留该绘制策略，已撤回。最终仍使用 ADR 0012 的 16 ms 普通队列重绘请求；没有冻结时钟、提前数字、忙等待或新增线程。

## 验证与取舍

状态轮询先修改测试并在旧实现上观察失败，再实现固定检查周期，核心测试通过。绘制实验沿用已有现场取时、关闭、取消与实际接收回归；不为一行框架调用添加实现镜像测试。无采样基线与候选按不同 Label 保存，完整记录过期、未接收和尾部迟到；固定 4000 ms 的配对不能替代默认 1800 ms 场景。

公网授时仍保持既有单样本策略和用户同步间隔。当前没有足够证据确定多样本平均/最小 RTT 的真实精度优势：不同样本可能共享不对称延迟，保留旧低 RTT 锚点还可能延迟真实校正并扩大振荡器漂移。没有实现未经验证的平均、静默换源或额外请求；网络估计误差与画面滞后分别报告。

测试采集增加有界 LeadMillis（默认 1800 ms），用于独立固定等待组，非默认值不接受时钟/长等待模式；不改变产品调度。恢复普通应用时先启动它，再重连模拟器无障碍服务，避免在 force-stop 状态下恢复设置；不改变生产授权流程。

最终保留策略与结果以 [优化计划](../OPTIMIZATION_PLAN.md) 及后续结果为准。当前证据不支持对任意目标应用、系统负载、网络或真机作硬实时承诺。
