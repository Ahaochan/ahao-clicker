# ADR 0017：分别记忆定时单点与多点浮窗尺寸

- 日期：2026-10-30。
- 取代ADR 0015、0016中的“关闭后恢复默认尺寸”；其他布局和执行规则继续沿用。

两种控制浮窗分别保存宽高，互不覆盖。左右下角的有效缩放手势结束时，通过既有SettingsStore异步保存到SharedPreferences；拖动过程、移动窗口、时钟刷新和自动恢复不写入。没有新增依赖、线程或定时任务。单点与多点共用保存/恢复逻辑，按钮保持同排、窄窗收紧图标和留白，准星独立。

以dp浮点数保存，避免密度变化后逻辑尺寸失真。缺失、非法、非正或非有限值忽略，采用原默认大小。恢复发生在窗口加入WindowManager之前：按当前密度转为像素，限制在排除系统栏和刘海的可用区域，按最终宽度计算最小高度，并把初始位置移回区域内。自动裁剪不覆盖保存值，回到较大可用区域仍可恢复原尺寸。仅记忆尺寸，不记忆窗口位置，也不恢复任何点击任务。

验证包含纯JVM边界与编解码测试、模拟器左右角真实拖动、关闭重开、两种模式独立、横屏裁剪后回到纵屏，以及不同进程中的磁盘持久化重读。点击调度和校时算法不变，本轮不重新评估性能或毫秒精度。
