# ADR 0008：第二步显示准星与触发时取点

- 日期：2026-10-26。
- 状态：已实现，48 个单测与完整 24 项模拟器场景、Lint 和 Debug/Release 构建通过；本轮未验证真机。
- 用户决定：去掉独立定位按钮，第二步显示准星，允许等待期间拖动，定时点击最新位置。
- 取代 ADR 0004 中确认点位、启用后锁定位置的决定；一次资格、固定时间参考、停止与过期不补点继续保留。

后续：浮窗坐标段落和常驻状态已由 [ADR 0009](0009-overlay-time-editing.md) 移除，最新点位维护与单次派发规则保留。

## 实现

第二步同时打开时钟控制窗与准星，恢复当前屏幕的有效历史点位或使用屏幕中心。拖动消费触摸，浮窗更新实际中心；仅初始化、松手与触发快照时按变化持久化，不按移动帧写入。主页面复用原有 500 ms 检查刷新坐标，无新后台循环。

core 的 OneShotRunner 接受点位提供器，仅在触发回调消费一次资格后求值；静态点位调用保留兼容。取消不求值，提供器失败消耗资格且不重试。Android 点位提供器读取准星实际中心，派发前再次校验显示尺寸、锁屏、边界和控制窗覆盖。

准星在等待阶段始终可触摸、可拖动。为避免挡住自己的注入点击，到达时立即移除准星输入窗口，保留可取消的 50 ms 输入生效等待，再派发；超过原有 250 ms 迟到边界则停止，不补点。同步移除窗口后立刻注入曾出现完成回调成功而目标零接收，已有失败与修正验收记录；手势结束后等待 500 ms 输入队列稳定再恢复同一准星。旧窗口身份检查与关闭时移除回调确保取消、断开、关闭或新窗口不会被迟到回调重新打开。临界时刻仍受 Android 输入调度影响，不承诺硬实时精度。

## 验证

先以核心测试和第二步界面断言复现旧版失败；用独立目标实际接收验证启用后从 A 拖到 B 仅点击 B、拖动本身零点击、完成恢复准星，以及停止/关闭/断开零补点。最终执行结果以 [验证记录](../VERIFICATION.md) 为准。
