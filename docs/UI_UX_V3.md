# 双页签与独立时间模块

计划日期：2026-10-25，实施与验收：2026-10-26。范围：保留原生 Views，不新增生产依赖。

## 实施计划

1. 先测试内置 HTTPS 来源、毫秒间隔边界、独立限频与时钟偏差格式。
2. 把校时网络、来源管理与时间页放在 app 的 time 功能包；core 保留平台无关规则。来源共用至多两个网络线程，各自保存样本、失败状态与取消代次。
3. 首页分为“自动点击”“时间同步”。点击页移除校时入口与状态，保留单击、连点、多点及权限入口。
4. 时间页两列显示京东、淘宝和已有 NTP 来源；点击来源切换任务参考。同步间隔改为数字输入，单位毫秒，明确校验范围。最后成功样本可继续推算，失败和过期必须标识；从未成功的来源不显示伪造时间。
5. 更新自动验收，执行单测、Lint、Debug/Release 构建及模拟器回归，记录实际 API 可达性。

## 布局

自动点击页按设置顺序展开；前两步的状态使用文字和颜色双重表达：

```text
┌────────────────────────────────────┐
│ [ 自动点击 ● ]    [ 时间同步 ]      │
│ 第一步 · 设置无障碍服务             │
│ 不可用 · 无障碍服务未连接（红色）   │
│ [ 启用无障碍点击服务 ]              │
│ 第二步 · 设置浮窗                   │
│ 不可用 · 请先完成第一步（红色）     │
│ 由无障碍服务提供，无需额外浮窗权限   │
│ [ 显示 / 隐藏浮窗和准星 ]             │
│ 第三步 · 配置点击任务               │
│ [ 定时单击 ] [ 连点 / 多点 ]        │
│ 准星、时间选择器、任务配置……         │
└────────────────────────────────────┘
```

本应用服务启用且实际连接后，前两项分别显示绿色“可用 · 无障碍服务已连接”“可用 · 浮窗已就绪”。只复用点击页可见时的 500 ms 延迟检查，离开取消、返回立即重查；第二步仍需主动点击，同时显示时钟与可拖动准星，松手自动保存；主页面不提供单独定位或确认入口。使用 [Android 无障碍专用窗口](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_ACCESSIBILITY_OVERLAY)，不申请普通应用浮窗所需的额外权限。

```text
┌────────────────────────────────────┐
│ [ 自动点击 ]    [ 时间同步 ● ]      │
├────────────────────────────────────┤
│ 时间来源                           │
│ 点选来源，用于定时点击和悬浮时钟     │
│ ┌────────────────┬───────────────┐ │
│ │ 京东           │ 淘宝          │ │
│ │ 23:59:59:700    │ 23:59:59:100  │ │
│ │        (+800)  │        (+200) │ │
│ ├────────────────┼───────────────┤ │
│ │ 阿里云         │ 腾讯云        │ │
│ │ …              │ …             │ │
│ ├────────────────┼───────────────┤ │
│ │ Cloudflare     │               │ │
│ │ …              │               │ │
│ └────────────────┴───────────────┘ │
│ 当前参考：京东 · 已同步             │
│ 同步间隔  [ 60000        ] 毫秒     │
│ [ 保存并同步 ]                     │
└────────────────────────────────────┘
```

卡片第一行为名称，第二行为 `HH:mm:ss:SSS(+800)`，窄屏或大字体允许第二行内部折行，避免缩小用户设定的字体。正值表示来源时间领先本机；偏差单位为毫秒。主标题用系统粗体，数据使用等宽数字；沿用现有绿强调色与深浅主题，通过边框及“当前参考”文字共同说明选中状态，不增加装饰动画。

## 同步与显示

- 默认间隔 60000 毫秒；输入接受 1000～86400000 毫秒。HTTPS 来源至少间隔 1000 毫秒，已有 NTP 来源仍至少 60000 毫秒。页面明确说明 NTP 下限，不偷偷改写输入。
- 刷新显示每 100 毫秒一次，以单调时钟推进最后成功样本；毫秒是显示单位，不代表逐毫秒刷新或绝对校时精度。
- 同步间隔从请求开始计时；超时来源不阻塞其他来源的显示。失败不覆盖其他来源或上次成功样本，未成功显示“尚未同步”；5 分钟以上样本标为过期。
- 只有时间页可见时同步所有来源；切走后只维护点击/时钟所需的所选来源。无页面、任务或时钟时取消网络与计划，不在后台常驻比较。
- 保存、选择来源不启动点击；执行中禁止更换参考及同步间隔，任务继续使用启用时冻结的参考。
- 京东、淘宝为公开 HTTPS 接口适配，接口可能变动或被网络拦截；显示失败，不回退为伪造的供应商时间。

## 验收条件

- 两页签可切换，旋转后保留当前页签与尚未保存的间隔。
- 自动点击页不出现校时配置；时间页显示两列来源与可编辑毫秒间隔。
- 正负与零偏差格式正确；来源样本隔离，停止观察取消周期同步，HTTP/NTP 限频独立。
- 定时单击使用时、分、秒、毫秒四列滚轮，传统连点仍使用日期选择器；保持一次点击、录制、停止、取消及回调失效语义。
- 同一物理屏幕收到配置通知时保留准星与已选位置；实际尺寸或旋转变化才停止并要求重新定位。屏幕标识统一采用物理尺寸与旋转，旧标识首次升级后需重新选位。
