# 精简浮窗与时间交互

最新小尺寸交互：浮窗可缩至128dp宽，播放/停止、加号、移动、关闭始终同排；窄窗缩小按钮、图标和内边距，取消两行布局。时钟适配可用宽高，定时时间单行缩放，小窗只显示时间。见[ADR 0016](decisions/0016-responsive-overlay.md)。

2026-10-30补充：定时单点和多点控制浮窗采用半透明深色底（70%不透明），文字、图标不透明。左右下角显示对称角标，按住任一角标可改变宽高；停止后可调整，执行时冻结。按钮和底角固定，内容区可滚动，准星不参与缩放。两种浮窗分别记忆尺寸，关闭重开及重启应用后恢复；屏幕变化时限制在安全区域，自动裁剪不覆盖保存值。详见[ADR 0017](decisions/0017-overlay-size-memory.md)。

日期：2026-10-26。用户选择：点击时间编辑；播放直接启停，只有时间缺失或已过期时才打开滚轮。此方案取代旧版首页“准备定时”和时间按钮流程。

## 首页

首页只保留两步，移除第三步、模式切换、点位摘要及旧连点表单。2026-10-30启用多点点击入口，第二步的两个浮窗互斥；多点采用加号手动增加准星，不做触摸录制。

```text
第一步 · 设置无障碍服务
可用 / 不可用
[启用无障碍点击服务]

第二步 · 设置浮窗
可用 / 不可用
[开启定时点击浮窗]
[开启多点点击浮窗]
```

定时入口同时打开时钟和准星，重复点击保持已打开的浮窗，不启动或停止点击任务；关闭使用浮窗右上角 ×。开始时间与启停都在浮窗完成。底层历史连点和录制引擎保留回归测试，但没有对应的公开入口。

多点浮窗复用时钟与控制条样式，去掉开始时间，播放与四向移动之间增加加号。默认一个准星，加号逐个增加，中心数字表示点击顺序；轻点准星可设置延迟或删除此点，拖动只定位、不点击下层。删除后重新连续编号，最多50点，保存点位与延迟；屏幕坐标空间变化后不复用旧点位。

```text
┌──────────────────────┐
│ ▶    ＋    ↔    ×    │
│ 12:59:59:750         │
└──────────────────────┘

      ─ 1 ─      ─ 2 ─      ─ 3 ─
       准星中心为序号，可拖动、轻点设置

┌ 第 2 次点击 ──────────┐
│ 延迟（毫秒） [1000]  │
│ 删除此点  取消  确定 │
└──────────────────────┘
```

用户更新为按1、2、3…持续循环，直到点击浮窗停止。第一点延迟从播放开始，之后从上一点的点击开始计时；末点后按第一点延迟进入下一轮，默认1000ms，整数范围0..86400000ms。运行中的编号准星始终显示，让触摸穿透而不拦截点击；停止后仍保留显示并恢复拖动、编辑。关闭、切换和系统中断仍停止且不自动继续。平台串行派发和极短首延迟的输入准备下限见[ADR 0014](decisions/0014-multipoint-overlay.md)。

每次真正新开浮窗，日期和小时取打开瞬间的当前参考时间，分、秒、毫秒沿用最后一次滚轮确认的值；尚无记录则全部取当前时间。它是供微调的固定初值，不随时钟不断变化；再次点击已有浮窗入口不重置。只有点“确定”才更新记忆，取消不覆盖；关闭再开或重启应用也保留分秒毫秒，小时重新取当前值。打开不自动启用，默认值已过时点击播放仍进入滚轮确认，不补点。

## 浮窗

```text
┌────────────────────────┐
│ [▶ / ■] [四向拖动] [×]│
│ 13:13:13:672            │
│ 开始点击             ✎ │
│ 13:15:00:750            │
└────────────────────────┘
```

只保留三个图标、当前时间和开始时间。开始时间整块可点击，最小触摸高度 56 dp，有点击反馈和读屏名称；未设置明确标记。坐标不再作为文字显示，直接用准星定位。完成或失败通过图标复位与短提示表达，不保留段落。

| 操作 | 结果 |
| --- | --- |
| 点击开始时间 | 打开时、分、秒、毫秒四列滚轮，确定仅保存，不启动 |
| 点击播放，时间有效 | 直接按最新准星位置启用一次定时 |
| 点击播放，时间缺失/过期 | 打开同一滚轮，确定后开启；取消保持停止 |
| 已启用时修改时间 | 提示先停止，保留当前任务，临近触发时锁定参考 |
| 点击停止 | 取消未来派发，保留浮窗 |
| 关闭、断开或屏幕中断 | 取消调度，关闭时间选择器与浮层，不恢复任务 |

滚轮属于无障碍服务的专用窗口，不申请普通浮窗权限，也不需要回到首页。确认时按所选时间来源决定今天/下一次发生时刻，仍只执行一次；校时过期、点位越界或控制窗覆盖点位继续阻止开启。

## FPS 准星

```text
           ┃

    ━━     ·     ━━

           ┃
```

四段短线在中心留空，中间一个小点表示真实点击位置。使用明亮绿 #7CF57A 加深色 #18231E 描边，提高不同背景上的识别度。视觉标记约 30 dp，透明拖动区域保持 64 dp；拖动和触发取点规则不变。不引入位图、动画、生产依赖或额外循环。

现有页面使用浅底 #FAFAFA、深色正文 #18231E、次要文字 #46564D 和主色 #216E4A；时钟保留等宽数字。只改变定位标记的辨识度，周围控件保持克制。

计时优化后，准星在截止前约 100 ms 收起进行输入准备，以最后可见中心点击；长等待采用有效周期校时，最后 5 秒锁定参考，异常校时停止。详见 [ADR 0010](decisions/0010-deadline-and-clock-discipline.md)。
